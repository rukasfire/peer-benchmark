一、專利規模對標 Portfolio Scale Benchmark

彙整各家「對外披露 / 資料庫口徑之專利總量」。家具五金兩巨頭（Hettich、Blum）以數千件專利遙遙領先；川湖以 3,752 件核准居「伺服器滑軌」賽道之首，且幾乎「申請即核准」。南俊未公開具體數量（主打快速 NPI）。

口徑差異（重要）：各公司披露方式不同，不可直接橫向加總。 • 川湖 3,752＝核准件數（2026-08，TW+US+CN+JP+DE+UK+EU+CA 多國同族合併前的申請件數口徑之一）；公司亦自陳「專利逾 3,600 項」。 • Hettich 4,554＝PatSnap 列 Paul Hettich GmbH 總專利族；公司自陳另有「over 1,000 active / 6,000 global」兩種口徑。 • Blum 2,000＝公司自陳 global 國際專利（多源：2009 年「逾 2,000」、產業部落「2,600」）；IDiyas 列 USPTO 僅 458 / EPO 450。 • Accuride 421＝PatSnap；Wikipedia 寫「nearly 400 enforceable」。富世達 463＝全球累積取得（含 196 發明專利）。南俊未公開，以 N/A 表示。

二、商業化強度雷達 Commercialization Strength Radar

六維度評分（0–100，分析師依公開資料給定之相對分級）：專利規模、技術專精度、商業化實證（毛利/市佔）、地理可執行、授權/聯盟網、成長動能。注意：本雷達比的是「專利強度的不同面向」，而非同賽道勝負——川湖/南俊/富世達屬伺服器滑軌賽道，Accuride/Hettich/Blum 屬家具五金賽道。

讀圖重點

川湖 (紫)：技術專精度、商業化實證、成長動能三軸拉滿——伺服器滑軌規格共定者、87% 毛利、80% AI 市佔，且與 NVIDIA / CSP 綁定。

南俊 (藍) / 富世達 (青)：真正的同賽道威脅。南俊是二供（議價權受限，聯盟軸弱）；富世達以「轉軸+液冷快接頭+滑軌」跨界整合，成長動能極強。

Accuride (橙)：老牌工業/家具滑軌，地理可執行強（美德中英日墨中多國製造），但成長與聯盟偏弱，且曾是川湖在美國的防禦對象。

Hettich (綠) / Blum (粉)：家具五金專利巨獸，地理可執行與專利規模頂滿，但技術專精度集中在「家具」、成長走成熟穩定路線，與川湖非直接競爭。

五、川湖的相對位置與策略含義 Strategic Read

1. 護城河型態根本不同。川湖走的是「專利收稅」模式——滑軌佔機櫃成本不到 1% 卻是安全件，客戶寧付高價買保險，87% 毛利即 IP 定價權的直接體現。Hettich / Blum 專利更多，但家具五金競爭激烈、走「規模＋品牌」路線，毛利遠低於川湖。兩者不在同一獲利邏輯。

2. 真正威脅在同賽道，不在家具派。南俊（二供分散風險）、富世達（滑軌＋液冷統包跨界）才是川湖在 AI 伺服器賽道的實質競爭者。富世達的「專利迴避設計 + 液冷整合」尤其值得盯——它讓系統廠採購一站式化，直接蠶食純滑軌廠的談判位階。

3. 專利網的「嚇阻」功能已驗證。川湖主動維權且勝訴（聯德中國最高法終審勝訴、防住 Accuride 美國案、對利安特等提告）。Accuride 作為家具滑軌老牌仍被列為防禦對象，說明川湖把專利當「進入壁壘」經營，而非裝飾。

4. 跨界威脅要預警。Hettich / Blum 擁有數千件精密機構專利與全球製造網，目前聚焦家具；但若資料中心「薄型高荷重滑軌」需求外溢，憑其專利池與精密製造能力，具備成為潛在跨界競爭者的條件。川湖應持續拉高轉移/鎖定/理線的專精度門檻。

5. 變現路徑最乾淨。相較錼創「等產業放量」、家具派「走規模」，川湖專利強度已即時轉化為營收與毛利（2025 營收 175 億、年增 73%）。風險在估值已反映 2027 與單一客戶（NVIDIA 系）集中——這也是南俊「二供」與富世達「跨界」能拿到的議價空間來源。
